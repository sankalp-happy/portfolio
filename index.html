Experience Two paid engagements. What I owned, and when.

Machine learning intern

Kapture CX · Bangalore · June 2026 to present

LLM serving on vLLM, for a 31B model on H200s. vLLM reuses a cached prefix only when the shared front of a prompt is byte-identical, so I restructured the prompts until it was and retuned the serving flags around that. The weights and the hardware stayed where they were, and the same box now holds more requests.

I also benchmarked GPTQ and AWQ quantization against the unquantized configuration, and argued for vLLM-router over nginx round-robin. Round-robin hands a request to whichever replica is next, which throws away the prefix the tuning just bought.

ML and backend engineer, freelance

Southern Railway · Remote · March to June 2026

RDSO engineering standards live on RailNet and had to reach engineers over the internet. The source portal reuses a document's URL when it revises the file, so the first build watched the link set, found it unchanged every week, and propagated nothing while standards were being revised underneath it.

The ETag is the one thing that moves. The crawler stores one per URL and treats a delta as the evidence a document changed. Only changed rows leave RailNet, on a weekly cron, and nothing is deleted.

Projects An LLM gateway and a prescribing system. Both deployed, both linked, one figure each.

SwitchBoard↗ live site, opens in a new tab

An LLM gateway that keeps three providers behind one endpoint, and recognises a question it has already answered.

One endpoint in front of Groq, Google and Anthropic. A semantic cache answers repeat questions instead of the provider, and keys rotate the moment one hits a rate limit. The application layer never learns that a provider degraded.

The cache compares prompts by cosine similarity rather than by hash, which is the only reason it catches a question asked in different words. Swapping a provider takes a config edit.

PharmaGuard↗ live site, opens in a new tab

Prescribing guidance read off a genomic file, in a system where the model does not get to make the call.

A genomic VCF goes in and CPIC-guided prescribing guidance comes out. A deterministic risk engine makes every clinical call, and the model writes one thing only, the explanation a clinician reads, after the decision is already final.

Wiring it that way is what makes an LLM admissible here at all. If the model fails, the clinician loses the prose and keeps the recommendation.
